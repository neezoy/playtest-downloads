# Village to Kingdom — playtest

A city builder about growing an island settlement, moving resources through busy streets and supplying its defenses.

[**Download the latest playtest for Windows, Linux or Mac**](https://github.com/neezoy/playtest-downloads/releases/tag/v2026.10.23.6)

| Linux 64-bit | `VillageToKingdom-2026.10.23.6-linux-x64.zip` | Extract everything, then run `Start-VillageToKingdom.sh`. |

Keep the extracted files together. You do not need to install Godot or .NET. More launch instructions are included in each ZIP.

The Mac build is experimental and awaits testing on actual Mac hardware. Intel requires macOS 12 or later; Apple Silicon requires macOS 13 or later. The app is ad-hoc signed, not notarized. If macOS blocks a trusted download, see [Apple's opening instructions](https://support.apple.com/102445).

## Playing and reporting issues

Use New Game to name a kingdom, or Continue/Load Game to resume one. Escape cancels the active tool or opens the pause menu. Options includes display, music, ambience and sound-effect settings.

Back up existing saves before trying a new version. Include your operating system, CPU/GPU, release version and the steps that caused a problem when reporting it. A screenshot or short recording helps. Check logs and saves for personal information before sharing them publicly.

This is an early playtest. This update improves placement responsiveness and distant shadow transitions. Large terrain reveals can still hitch; reported Windows terrain artifacts and low-angle foliage issues remain under investigation. The extracted Linux package passed native menu/save/load checks. Native Windows and Mac playtesting of this upload remain pending.

This repository distributes playable builds and release notes only. The game's editable source project is not published here.
